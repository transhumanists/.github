# Contributing

Thanks for your interest in improving this project!

## Reporting bugs
- Open a **Bug report** issue and fill in every field - exact steps, expected vs actual behaviour, and your OS/Python version.
- For security vulnerabilities, please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Suggesting features
- Open a **Feature request** issue describing the problem you are trying to solve, not just the solution.
- Small, focused PRs are merged faster than large rewrites.

## Pull requests
1. Fork the repo and create your branch from `main`.
2. Keep changes minimal and related to a single purpose.
3. Make sure existing tests pass and add tests for new behaviour where practical.
4. Update documentation (README / docstrings) when behaviour changes.

## Style
- Python: PEP 8, type hints where reasonable.
- Keep dependencies minimal; prefer the standard library.

By participating you agree to uphold the [Code of Conduct](CODE_OF_CONDUCT.md).
