# .github

The organisation-level home for **[transhumanists](https://github.com/transhumanists)**.

## Where the actual profile lives

The org landing page at [github.com/transhumanists](https://github.com/transhumanists)
is rendered from **`profile/README.md`** in this repository. That file is the
single source of truth for the org's scope, its seven verticals, and how to
contribute a record or a source.

If you are here to read what this org does, read
**[`profile/README.md`](profile/README.md)**.

## One rule

**Do not duplicate the profile text here.** A second copy drifts within weeks and
then two landing pages disagree about what the org is. Edit `profile/README.md`
instead — including the vertical figures, which the profile owns.

The two SVGs are referenced by the profile README, so renaming either one breaks
the org landing page. If you change them, update `profile/README.md` in the same
commit.
